MODEL COMPARISON

Cyber Kill Chain vs. Diamond Model of Intrusion Analysis

Two complementary lenses for deconstructing complex enterprise intrusions.

LOCKHEED MARTIN CYBER KILL CHAIN
  • Philosophy: Strictly linear, sequential progression of 7 phases.
  • Defensive Goal: Break any single link to completely disrupt the attack.
  • Phases: Recon ➔ Weaponize ➔ Deliver ➔ Exploit ➔ Install ➔ C2 ➔ Actions on Objectives.
  • Limitation: Poorly models modern internal lateral movement, Living-off-the-Land tradecraft, and insider threats.
CALTAGIRONE DIAMOND MODEL
  • Philosophy: Non-linear, relational graph of vertices and meta-features.
  • Defensive Goal: Mathematical pivoting to discover unknown adversary infrastructure.
  • Vertices: Adversary ➔ Capability ➔ Infrastructure ➔ Victim.
  • Strength: Excels at mapping supply-chain intrusions, cloud breaches, and multi-stage campaign evolutions.
[SAY:] The Cyber Kill Chain is like an assembly line: break one link and the whole chain halts. But modern adversaries do not walk in a straight line! They loop, they pivot, they live off the land. That is why we combine the Kill Chain's temporal phases with the Diamond Model's relational graph. [PEDAGOGY:] Use the assembly line analogy for Kill Chain, and the detective conspiracy board analogy for Diamond Model.

ADVERSARY BEHAVIOR

MITRE ATT&CK Matrix Architecture & 3D Topology

The Common Language of Defensive Engineering: 14 Enterprise Tactics & 3D Attack Paths

Tactics (Why) vs. Techniques (How)

MITRE ATT&CK organizes real-world adversary behavior into 14 sequential tactical objectives (from Reconnaissance to Impact). Each tactic contains granular techniques and sub-techniques.

TACTIC: Credential Access [TA0006]
  └ TECHNIQUE: OS Credential Dumping [T1003]
     └ SUB-TECH: LSASS Memory [T1003.001]
     └ DETECTION: Sysmon Event ID 10 (ProcessAccess)
🕸️ 3D ATTACK SURFACE TOPOLOGY // REAL-TIME MESH
Active nodes: Gateway (Cyan), DC Server (Amber), Workstations (Green), SCADA PLC (Red).
[SAY:] Notice the hierarchy: Tactics are the WHY (Execution). Techniques are the HOW (PowerShell). Procedures are the WHAT (the exact base64 command). The adversary can change their IP, but they cannot hide their procedure. [PEDAGOGY:] Establish the Tactic ➔ Technique ➔ Sub-technique ➔ Procedure hierarchy.
TACTICAL BREAKDOWN

The 8 Core Enterprise Tactics: Initial Access to Impact

Understanding the standard kill chain progression through the ATT&CK lens.

1. Initial Access

Spearphishing attachments (T1566), valid VPN credentials, public edge exploits.

2. Execution

PowerShell (T1059.001), Windows Command Shell, WMI process execution.

3. Persistence

Registry Run keys (T1547), Scheduled Tasks (T1053), service creation.

4. Privilege Escalation

Token impersonation, DLL search order hijacking, Kerberoasting (T1558).

5. Defense Evasion

Living-off-the-Land (LOLBins), process injection (T1055), log clearing.

6. Discovery

Network share scanning (T1135), AD enumeration (nltest /dclist).

7. Lateral Movement

Pass-the-Hash (T1550.002), Remote Desktop Protocol, SMB file execution.

8. Exfiltration & Impact

Automated cloud sync exfil (T1567), data encryption for ransom (T1486).

[SAY:] Walk through these eight core tactics. Notice how an attacker moves from Initial Access down to Exfiltration and Impact. Every tactic leaves telemetry behind. [PEDAGOGY:] Guide students to view intrusions not as isolated events, but as a linked chain of tactical goals.

DEFENSIVE ONTOLOGY

MITRE D3FEND: The Countermeasure Knowledge Graph

While ATT&CK catalogs offense, D3FEND catalogs precise defensive engineering countermeasures.

MODEL & DETECT
  • Process Lineage Analysis: Trace parent-child relationship (Word ➔ PowerShell).
  • File Access Pattern: Detect rapid mass file encryption signatures.
  • Identifier Activity Analysis: Detect pass-the-hash ticket reuse.
ISOLATE & DECEIVE
  • Process Segment Execution: Constrain unsigned binaries in isolated containers.
  • Decoy Environment: Deploy honeypot Active Directory accounts (honeytokens).
  • Network Traffic Filtering: Null-route suspicious egress IP sockets.
EVICT & RESTORE
  • Credential Invalidation: Force immediate Kerberos TGT double-reset.
  • Process Termination: Surgically kill injected memory threads.
  • Artifact Eviction: Remove malicious scheduled tasks and persistence keys.
[SAY:] ATT&CK tells you how you get attacked; D3FEND tells you how to engineer the defense. Notice the categories: Model, Detect, Isolate, Deceive, and Evict. [PEDAGOGY:] Introduce D3FEND as the engineering balance to ATT&CK offense.
