TELEMETRY CORRELATION

Multi-Source Telemetry: The Triad of Visibility

No single sensor sees the entire attack. True visibility requires multi-source correlation.

1. HOST TELEMETRY
Windows Events, Sysmon, EDR

What executed? Process trees, command lines, loaded DLLs, memory injections, registry modifications. Strength: Exact process and user attribution.

2. NETWORK TELEMETRY
Zeek, Suricata, NetFlow, PCAP

Where did it communicate? Byte volumes, TCP flags, DNS queries, TLS certificates, HTTP headers. Strength: Unforgeable wire truth.

3. CLOUD / IDENTITY
Entra ID, AWS CloudTrail, Okta

Who authenticated? MFA tokens, token theft, service principal activity, abnormal geolocations. Strength: Identity plane tracking.

[SAY:] Correlating host and network telemetry is like checking both the college main gate security register and the hostel warden's sign-in sheet. If a student says they were in the hostel studying at 10 PM, but the main gate register shows their bike leaving at 9:45 PM, the discrepancy tells you the truth. In cyber defense, an attacker can modify their command line, but they cannot erase the firewall connection record and the Zeek conn.log simultaneously. [PEDAGOGY:] HUMOR ANCHOR: Hostel warden's sign-in sheet vs. main gate security register. Explains why combining host and wire data defeats adversary evasion.
HOST INTERNALS

Windows Security Auditing: Essential Event IDs

The standard Windows Event Log security baseline for detection engineers.

EVENT ID 4624: LOGON TYPES
TypeLogon Mechanism & Operational Context
Type 2Interactive Logon (Physical keyboard & screen)
Type 3Network Logon (SMB, PsExec, Pass-the-Hash!)
Type 7Unlock Workstation (Screen unlock)
Type 10RemoteInteractive (Remote Desktop Protocol / RDP)
EVENT ID 4688: PROCESS CREATION

Records every binary executed on the system. Requires GPO policy "Include command line in process creation events" enabled.

Creator Process: C:\Windows\explorer.exe New Process Name: C:\Windows\System32\cmd.exe Process Command Line: cmd.exe /c whoami /priv
[SAY:] Memorize Logon Type 3. When an attacker executes Pass-the-Hash or moves laterally using PsExec, Windows records Logon Type 3 (Network). If you see an administrative account logging in via Type 3 at 3:00 AM from a DMZ workstation, sound the alarm. [PEDAGOGY:] Emphasize Logon Type 3 and Type 10 as the core indicators of lateral movement.
SYSINTERNALS SYSMON

Microsoft Sysmon: The High-Fidelity Endpoint Sensor

System Monitor bridges the gap between basic event logs and commercial EDR agents.

EVENT ID 1
Process Create

Captures full command line, parent process lineage, image hashes (MD5, SHA-256), and original file name.

EVENT ID 3
Network Connect

Binds the exact process ID and binary image to an outbound destination IP, port, and protocol.

EVENT ID 10
Process Access

Detects process injection (T1055) and LSASS memory dumping (Mimikatz accessing lsass.exe).

EVENT ID 22
DNS Query

Logs the exact query string, resolved IP, and originating process ID (detects C2 domain resolution).

[SAY:] Look at Sysmon Event ID 1: Process Creation. We look at the parent-child relationship. If Word launches PowerShell, which launches CMD, which launches Certutil... colleagues, that is not Microsoft Word doing document formatting! That is like your younger brother borrowing your motorcycle at 2:00 AM wearing a helmet and carrying a crowbar! You don't need an audit committee to know something suspicious is taking place. [PEDAGOGY:] HUMOR ANCHOR: The younger brother borrowing your bike at 2:00 AM with a crowbar! Memorable analogy for malicious process trees.
WIRE TELEMETRY

Zeek (formerly Bro): Structured Protocol Brokering

Zeek converts unstructured network packet chaos into clean, structured tab-delimited logs.

conn.log (Connections)

Every TCP/UDP session. Tracks originating/responding IPs, ports, duration, byte counts, and connection state (e.g., SF for normal, S0 for scan).

UID: Unique flow identifier
dns.log (DNS Queries)

Every domain query and response. Logs QTYPE (A, AAAA, TXT), resolved IPs, and TTL values. Detects DNS tunneling and DGA algorithms.

Linked by UID to conn.log!
ssl.log (TLS Sessions)

Server Name Indication (SNI), certificate subject, issuer, SHA-1 fingerprint, and JA3/JA3S client/server fingerprints.

Exposes C2 despite encryption!
[SAY:] Zeek is pure gold for SOC analysts. Notice the UID field. In Zeek, every single network conversation gets a unique connection ID—like CHhAvV31uWRrAc8oj6. If you see that UID in conn.log, you can grep that exact UID in dns.log, ssl.log, and http.log to reassemble the entire conversation. [PEDAGOGY:] Explain how Zeek's UID field ties disparate protocol logs into a unified investigation stream.

GENERIC DETECTION

Open-source, generic YAML detection signatures transpiled to any SIEM query language.

LAB-04: STEP 6 OF 7 // ERROR RESOLUTION & RECOVERY

Common Telemetry Analysis Errors & Fixes

Handling Pandas memory constraints and CyberChef decoding failures.

Issue 1: MemoryError when Loading 2,500 JSON Events

Occurs if Python tries to read the entire file into an unindexed single dataframe object.

# Recovery: Process in iterative chunks chunks = pd.read_json('auth_events.json', lines=True, chunksize=500) df_auth = pd.concat([c[c['EventID'].isin([4624, 4625, 4688])] for c in chunks])
Issue 2: CyberChef Output Shows Chinese or Garbled Characters

Encoding recipe set to UTF-8 or ASCII instead of UTF-16LE.

# Recovery: In CyberChef recipe panel: 1. Remove 'Decode text' or set encoding dropdown to 'UTF-16LE (1200)' 2. Verify that command text renders readable PowerShell syntax
[SAY:] If you see Chinese characters in CyberChef, you picked the wrong text encoding. PowerShell base64 is UTF-16 Little Endian. [PEDAGOGY:] Have students experiment switching between UTF-8 and UTF-16LE in CyberChef to see the difference visually.
